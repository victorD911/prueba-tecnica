"PANEL ADMINISTRATIVO DE E-COMMERCE
(INVENTARIO)"
catálogo de productos de una tienda en línea mediante un panel administrativo moderno e interactivo.

El sistema incluye autenticación simulada con LocalStorage, protección de rutas y gestión completa de productos (CRUD) consumiendo una API RESTful creada en MockAPI.

Entre sus funcionalidades principales se encuentran:

Inicio y cierre de sesión.
Visualización de productos en un listado administrativo.
Creación de nuevos productos con validaciones.
Edición de información de productos mediante modal interactivo.
Eliminación de productos con confirmaciones usando SweetAlert2.
Interfaz responsive y moderna con CSS personalizado.

Stack tecnológico:
React.js + Vite
React Router DOM
Hooks de React
SweetAlert2
MockAPI
CSS personalizado
LocalStorage

url de MockAPI: https://mockapi.io/projects/6a1659f11b90031f81b0ef2b

Instrucciones claras para clonar, instalar dependencias (npm install) y ejecutar en
desarrollo (npm run dev).
